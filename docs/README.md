# Open Technologies Portfolio Documentation

## Project role

This repository is the public presentation and evidence layer for Emeraude Kiangana's technology work. It should publish inspectable proof of work rather than act as a generic CV or claim unverified capability.

## Documentation map

- [Root README](../README.md) — project purpose, local commands and deployment model.
- [Project Status](PROJECT-STATUS.md) — factual deployment and evidence status.
- `proofs/` — project and skill proof records.
- `public/` — static public assets.
- `src/` — Next.js application source.
- `.github/workflows/` — deployment and proof CI.

## Publishing rule

A project page should distinguish:

- what is implemented;
- what has been tested;
- what has a public artifact;
- what remains experimental or unknown.

The portfolio publishes evidence produced elsewhere; it must not manufacture evidence for another project.
