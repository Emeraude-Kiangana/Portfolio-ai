# Open Technologies Portfolio Documentation

## Project role

P01 is the public presentation and evidence layer for Emeraude Kiangana's Open Technologies work. It publishes inspectable proof without replacing the originating project repositories.

## Documentation map

- [Root README](../README.md) — identity, purpose, evidence model, stack and deployment.
- [Project Status](PROJECT-STATUS.md) — factual P01 state and source synchronization.
- \`src/data/projects.ts\` — typed normalized project-card data.
- \`proofs/\` — portfolio proof records.
- \`public/\` — static public artifacts.
- \`src/\` — Next.js application source.
- \`.github/workflows/\` — CI and deployment workflows.

## Publishing rule

**P01 CLAIM ≤ SOURCE PROJECT EVIDENCE**

Every card separates:

1. project maturity;
2. public evidence availability;
3. version and demo state;
4. verified scope;
5. evidence links;
6. limitations;
7. source visibility;
8. last verification date.

Private source is not equivalent to blocked project. Public demo is not equivalent to open source. Public repository is not equivalent to licensed software.

The portfolio must not manufacture evidence for another project.
